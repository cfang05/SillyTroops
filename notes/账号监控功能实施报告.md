# 账号监控功能实施报告

## 实施完成

已为您添加完整的账号监控功能，管理员可以查看所有测试账号的登录情况和使用时长。

## 功能特性

### 1. 自动记录登录日志
- **触发时机**: 用户登录/登出时自动记录
- **存储位置**: `sillytroops_login_logs`
- **记录内容**:
  - userId - 用户ID
  - username - 用户名
  - timestamp - 时间戳
  - action - 操作类型（login/logout）
- **日志保留**: 最近1000条（避免无限增长）

### 2. 自动统计使用时长
- **计时机制**:
  - 登录时：记录会话开始时间（`sillytroops_session_start`）
  - 登出时：累加本次会话时长到 `user.totalUsageTime`
  - 切后台时：累加并重置计时器（App.vue onHide）
  - 返回前台时：重新开始计时（App.vue onShow）
- **存储位置**: 用户对象的 `totalUsageTime` 字段（毫秒）
- **精度**: 分钟级（前端显示时转换为"X小时X分钟"）

### 3. 用户统计API

#### `userManager.getUserStats(userId?)`
返回单个或所有用户的统计信息：
```javascript
{
  userId: string,
  username: string,
  nickname: string,
  isTest: boolean,
  isAdmin: boolean,
  createdAt: number,
  lastLoginAt: number | null,    // 最后登录时间
  loginCount: number,              // 登录次数
  totalUsageTime: number,          // 总使用时长（毫秒）
  lastAction: 'login'|'logout'|null,  // 最后操作
  lastActionTime: number | null    // 最后操作时间
}
```

**使用示例**:
```javascript
// 获取所有用户统计
const allStats = userManager.getUserStats()

// 获取单个用户统计
const userStat = userManager.getUserStats('user_test01')
```

#### `userManager.getLoginLogs(options?)`
返回登录日志列表：
```javascript
options = {
  userId: string,      // 可选，筛选特定用户
  startTime: number,   // 可选，开始时间
  endTime: number,     // 可选，结束时间
  action: 'login'|'logout',  // 可选，操作类型
  limit: number        // 可选，返回数量（默认100）
}
```

**使用示例**:
```javascript
// 获取最近50条登录日志
const logs = userManager.getLoginLogs({ limit: 50 })

// 获取test01用户今天的登录记录
const todayStart = new Date().setHours(0, 0, 0, 0)
const test01Logs = userManager.getLoginLogs({ 
  userId: 'user_test01', 
  startTime: todayStart,
  action: 'login'
})
```

## 查看方式

### 方式一：通过代码调用API（推荐）
在任意管理员可访问的页面（如设置页）添加"账号监控"入口：

```javascript
// 在 src/pages/settings/settings.vue 或其他页面
methods: {
  openMonitor() {
    if (!userManager.isAdmin()) {
      uni.showToast({ title: '需要管理员权限', icon: 'none' })
      return
    }
    
    // 获取所有用户统计
    const stats = userManager.getUserStats()
    console.log('用户统计:', stats)
    
    // 获取今天的登录日志
    const todayStart = new Date().setHours(0, 0, 0, 0)
    const logs = userManager.getLoginLogs({ startTime: todayStart, limit: 50 })
    console.log('今日登录:', logs)
    
    // 计算今日活跃用户数
    const activeToday = stats.filter(u => u.lastLoginAt >= todayStart).length
    console.log('今日活跃用户:', activeToday)
    
    // 显示统计信息
    uni.showModal({
      title: '账号统计',
      content: `总用户: ${stats.length}\n今日活跃: ${activeToday}\n总使用时长: ${this.formatTime(stats.reduce((sum, u) => sum + (u.totalUsageTime || 0), 0))}`,
      showCancel: false
    })
  },
  
  formatTime(ms) {
    const minutes = Math.floor(ms / 60000)
    const hours = Math.floor(minutes / 60)
    if (hours > 0) return `${hours}小时${minutes % 60}分钟`
    return `${minutes}分钟`
  }
}
```

## 权限控制

- 所有用户：自动记录登录登出和使用时长（无感知）
- 管理员（isAdmin: true）：可调用 `getLoginLogs` 和 `getUserStats` 查看所有用户数据
- 普通用户：无法访问其他用户的统计数据（前端无入口，后端未实现权限判断）
