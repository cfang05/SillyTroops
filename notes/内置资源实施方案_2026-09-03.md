# 内置资源实施方案（2026-09-03）

## 需求
将 st_card / st_preset / st_regex 文件夹中的文件作为项目自带资源，用户在新建对话时可主动选择，不自动导入Store，预设和正侧不替代默认配置。

   ```typescript
   import { loadBuiltinCharacters, loadBuiltinPresets, loadBuiltinRegexPresets } from '../../services/builtinAssets'

   async onLoad() {
     const chars = await loadBuiltinCharacters()
     this.builtinChars = chars.filter(c => !c.error)  // 过滤加载失败项

     this.builtinPresets = presets.filter(p => !p.error)
     
     const regexes = await loadBuiltinRegexPresets()
     this.builtinRegexPresets = regexes.filter(r => !r.error)
   }
   ```

## 技术细节

**条件编译语法**（已在 builtinAssets.ts 中实现）：
```typescript
// #ifdef H5
const res = await fetch(item.file)
const blob = await res.blob()
// #endif

// #ifndef H5
return { error: '小程序端需手动导入' }
// #endif
```

**不自动导入Store的原因**：
- 角色卡：避免污染用户自己的卡库，且3张内置卡用户可能不需要全部导入
- 预设：避免覆盖用户自定义预设，且用户可能只需临时使用
- 正侧：同理，用户可按需选择是否应用到当前对话

**用户选择流程**：
1. 首页 → "开始对话" → 新建对话页面
2. 新建对话页面展示"内置角色卡"列表 + "选择预设（可选）" + "选择正侧（可选）"
3. 用户点击内置卡 → 直接进入聊天（不经过卡库页面）
4. 用户选择内置预设/正侧 → 仅应用于当前对话，不修改默认配置
