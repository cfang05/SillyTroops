## 📊 总览：核心数据流对比

### 酒馆的聊天主链路

```
用户输入
  ├─ 输入侧正则 getRegexedString(text, USER_INPUT=1)
  ├─ 斜杠命令解析/执行
  │
  ▼ Generate(type, options, dryRun)
  ├─ 宏替换 substituteParams()
  ├─ 世界书扫描 getWorldInfoPrompt() → before/after/atDepth/outlet/EM
  ├─ 作者注 setFloatingPrompt()
  ├─ 扩展注入 vectors/summary/smart context
  │
  ├─ prepareOpenAIMessages()
  │   ├─ preparePromptsForChatCompletion() → marker 填充
  │   └─ populateChatCompletion() → 消息组装 + token 预算
  │
  ▼ sendOpenAIRequest() → SSE 流式
  │
  ▼ 流式接收 (StreamingProcessor)
  ├─ 输出侧正则 getRegexedString(text, AI_OUTPUT=2)
  ├─ Markdown 渲染 messageFormatting()
  └─ 写入 chat JSONL 存档
```

### 本项目的聊天主链路

```
用户输入
  │
  ▼ onSend()
  ├─ 输入侧正则 applyRegexScripts(text, placement=1)
  │
  ├─ PromptBuilder.buildMessages()
  │   ├─ WorldInfoEngine.scan() → before/after/atDepth 桶
  │   ├─ marker 提示词填充（硬编码 MARKER_IDS）
  │   └─ 按 promptOrder 组装消息数组
  │
  ▼ MessageProcessor.generateReply()
  │   ├─ VariableEngine.substituteVariables() → 宏替换
  │   └─ llmClient.chat() → 非 SSE，一次性返回
  │
  ▼ 收到回复
  ├─ 输出侧正则 applyRegexScripts(text, placement=2)
  ├─ BlockParser.parse() → 解析游戏标签（非 Markdown）
  └─ 写入 conversationManager.messages
```
