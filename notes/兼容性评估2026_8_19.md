## 3. 关键差距（按优先级，反映现状）

**P0 — 开箱即用 / 内容一致性**

1. 无内置默认预设：不导入酒馆预设时，角色 description/personality/scenario 和世界书一个都进不了上下文。
2. 示例消息不是真 few-shot：`_formatDialogueExamples` 仅按 `<START>` 切块拼接，未做 `name1:/name2:` 行解析与角色名替换。

**P1 — 世界书类/深度人设卡无差别**

3. 世界书 globalScanData 六源 `match_*` 缺失。
4. 世界书 AN/EM/outlet 桶不注入。
5. 世界书内容不走 WORLD_INFO 正则。
6. 作者注（Author's Note）整体缺失。
7. `depth_prompt` 不注入。
8. 正则函数替换 / substituteRegex / 深度过滤未实现。

**P2 — 体验边界**

9. 无 Markdown 渲染（`BlockParser` 只有游戏标签）。
10. 无真实 SSE 流式（`_simulateStream` 打字机模拟，`stream` 参数被忽略）。
11. 无 tokenizer（`estimateTokens` 中文=1/其它=0.25 粗估）。
12. `squash_system_messages`/`continuePrefill` 只导入未实现；`namesBehavior` 只实现 CONTENT=2。
13. `chat_metadata` 语义缺失（tainted/scenario 覆盖/chat_id_hash 等）。

**P3 — 远期/平台限制**

V3 卡 + `{{asset::}}`、世界书 min_activations、斜杠命令、标签系统、小程序 PNG 导入（`#ifdef` 隔离，可接受）。

## 4. 工程质量与风险

**优点**
- 引擎层纯函数化、类型边界清晰；`charCardParser.normalizeEntry` 对 `extensions` 原样保留（防往返丢信息）、`types/script.ts` 对 placement 编号差异的说明，都是高质量兼容设计。
- `#ifdef H5 / MP-WEIXIN` 双端隔离规范（PNG 导入、DOMPurify、LLM 端点）。
- 存储按用户 `scopedKey` 隔离；会话持久化 `worldInfoState/trpgState/localVariables`。

**风险**
1. 🔴 `utils/llm/client.js` 硬编码 DeepSeek API Key（`H5_DEFAULT_CONFIG.API_KEY`），前端打包即泄露。
2. 测试夹具混入仓库根目录：`character_card-exp.png`(2.2MB)、`preset-exp.json`(1.2MB)。
3. 两份世界书解析源并存：`utils/lore/charCardParser.js`（JS）与 `engine/WorldInfoEngine.ts`（TS），需防漂移。
4. 旧 TRPG 并行未清（详见 §6）。

## 6. 旧 TRPG 并行现状（待统一）

评估时点（2026-08-19）实测：

| 并行项 | 现状 | 结论 |
|---|---|---|
| `utils/engine/stateManager.js`（51KB，GAME_STATE 存储） vs 会话 `trpgState`（conversationManager） | `combatManager`/`item-manager`/`adventureManager`/`runtimeStore` 仍引用 stateManager；`chat.vue` 已改用会话 `trpgState` 初始化 | **两套状态系统并行，未收敛** |
| `utils/memory/*`（atomicEvent/interactionLog/storyFragment） vs conversationManager messages | `stateManager` 引用 atomicEvent；`adventureManager` 引用 interactionLog/storyFragment | 与对话存档功能重叠 |
| `utils/ai-helper.js` | 仅被 `client.js` 注释引用，无实际 import | **死代码** |
| `stores/runtimeStore.ts` 的 `syncFromStateManager` | 仍从 stateManager 同步场景 | 需切到会话 trpgState |

统一方向（依据 `notes/合并方案-执行序.md` 决策 6）：TRPG 运行时状态归属**会话（conversation）**，`stateManager` 逻辑迁纯函数，`memory/*` 由 conversationManager 取代，`ai-helper.js` 删除。
