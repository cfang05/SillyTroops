## 权限说明

### 测试权限（isTest: true）
- 可使用内置测试 API（无需配置自己的 API Key）
- 适用于快速测试游戏功能
- admin 和 test01~test05 均具有此权限

### 管理员权限（isAdmin: true）
- 仅 admin 账号具有
- 包含测试权限的所有功能
- 可访问"测试监控"页面查看所有测试账号使用情况

## 测试监控功能

admin账号登录后，首页会显示"测试监控"卡片（红色主题），点击可查看：

- **统计总览**：总用户数、今日活跃用户、总使用时长
- **用户详情**：每个测试账号的登录次数、使用时长、最后登录时间
- **登录日志**：最近50条登录/登出记录，支持时间筛选
- **Token用量**：占位显示（待后续实现）

## 账号创建机制

### 自动创建
- **时机**：应用启动时（App.vue onLaunch）
- **函数**：`userManager.ensureAdminSeed()`
- **逻辑**：
  1. 检查 admin 账号是否存在，不存在则创建（密码 admin123），存在则更新等级为15级
  2. 检查 test01~test05 是否存在，不存在则批量创建
  3. 已存在的账号不会重复创建，密码保持不变

### 用户注册
- **入口**：登录页面 → 注册tab
- **权限**：新注册账号默认具有测试权限（isTest: true）
- **等级**：新注册账号默认1级

## 清除旧账号数据

如果之前创建的admin账号密码不正确，可通过以下方式清除：

### H5端（浏览器）
1. 打开浏览器开发者工具（F12）
2. 进入 Application / 存储 标签
3. 找到 Local Storage → 清除 `sillytroops_users` 和 `sillytroops_current_user_id`
4. 刷新页面，系统会自动创建新账号

### 小程序端
- 在微信开发者工具中：工具 → 清除缓存 → 清除所有数据
