## 待实现功能（后续优化）

### Token统计
**位置**: `src/utils/llm/client.js`

需要在API响应处理中添加：
```javascript
// 解析响应中的usage字段
if (data.usage) {
  this._recordTokenUsage({
    promptTokens: data.usage.prompt_tokens || 0,
    completionTokens: data.usage.completion_tokens || 0,
    totalTokens: data.usage.total_tokens || 0
  })
}

// 记录到用户token统计
_recordTokenUsage(usage) {
  const userId = userManager.getCurrentUserId()
  const key = `u_${userId}_token_usage`
  const stats = uni.getStorageSync(key) || { totalTokens: 0, requestCount: 0 }
  stats.totalTokens += usage.totalTokens
  stats.requestCount++
  uni.setStorageSync(key, stats)
}
```

实现后监控页面会自动显示token用量（当前显示"待统计"占位）。

## 技术细节

### 数据存储
- **用户列表**: `sillytroops_users`
- **登录日志**: `sillytroops_login_logs`（最多保留1000条）
- **会话计时**: `sillytroops_session_start`
- **当前用户**: `sillytroops_current_user_id`

### 时长计算
```
登录 → 记录 session_start
登出 → 累加 (now - session_start) 到 user.totalUsageTime
切后台 → 累加时长并重置 session_start
返回前台 → 重置 session_start = now
```

### 权限检查
```javascript
// 首页菜单
if (userManager.isAdmin()) {
  menuItems.splice(5, 0, { id: 'monitor', ... })
}

// 监控页面
onLoad() {
  if (!userManager.isAdmin()) {
    uni.showToast({ title: '需要管理员权限' })
    uni.navigateBack()
  }
}
```
